1 · Foundations

1.1 Life of a Packet PACKET TRACER

The classic interview question. Host A opens https://www.example.com across routed hops. The single most important invariant: source/destination IP stay constant end-to-end; source/destination MAC are rewritten at every hop (until NAT rewrites the IP at the edge).

Fig 1. Life of a packet. MACs change per hop (teal labels), the IP pair is constant until the NAT router rewrites the source. Say this diagram out loud and you've answered the interview question.
Fig 2. Encapsulation. Each router strips and rebuilds only the outer (grey) layer; each NAT touches the teal layer; end hosts own everything inside.

1.2 VLANs & Trunks PACKET TRACER

A VLAN is a logical broadcast domain; a trunk carries many VLANs by inserting a 4-byte 802.1Q tag (12-bit VLAN ID → 4094 usable, 3-bit PCP for CoS). The native VLAN travels untagged — both ends must match or you leak traffic between VLANs.

interface gi0/24
 switchport trunk encapsulation dot1q
 switchport mode trunk
 switchport trunk native vlan 99
 switchport trunk allowed vlan 10,20,99
 switchport nonegotiate
Interview signal: explain the double-tagging attack (attacker on native VLAN stacks two tags; first switch pops one, second forwards into the victim VLAN) and why the fix is an unused, tagged native VLAN. OT VLANs segment but do not secure — IEC 62443 conduits need ACL/firewall enforcement on top.

1.3 Spanning Tree Protocol PACKET TRACER

STP elects one root bridge (lowest Bridge ID = priority + MAC), then every non-root switch selects its cheapest path; redundant paths block. Rapid PVST+ (802.1w) converges in under a second via proposal/agreement instead of 30–50 s timers.

Fig 3. Triangle topology: SW1 wins root (lowest priority), SW2/SW3 pick root ports (RP) toward it, and the SW2–SW3 link blocks on SW3's side (higher BID loses the designated-port election). PortFast on that blocked link's equivalent host ports + BPDU Guard is the hardening baseline.
War story to keep ready: a rogue low-priority switch plugged into access steals root → traffic hairpins through a 100 Mb closet switch. Root Guard on distribution downlinks err-disables the port the moment a superior BPDU arrives.

2 · Services

2.1 DHCP — DORA PACKET TRACER

Fig 4. DORA. Discover and Request are broadcasts (client has no IP yet); Offer/ACK come back from the server. Relay agents make it work across VLANs.

2.2 HSRP / VRRP first-hop redundancy PACKET TRACER

Fig 5. HSRP. Hosts point at an address no physical box "owns." Missing preempt = no failback after recovery — the number-one HSRP interview gotcha. VRRP is the open-standard sibling (Master/Backup, 224.0.0.18); GLBP adds real per-host load-balancing.

2.3 NAT/PAT in one line

PAT multiplexes an entire inside network onto one public IP by rewriting src IP:port and keeping a translation table — show ip nat translations is your truth. OT NAT at cell boundaries lets identical machine templates (same private IPs on every production line) coexist upstream.

3.2 EIGRP — DUAL in one picture PACKET TRACER

Fig 8. DUAL. The whole protocol in one inequality: a neighbor whose own distance (RD) is less than your best (FD) can never be routing through you — mathematically loop-free backup.

3.3 BGP best-path selection GNS3 / CML

BGP is policy, not shortest-path. Neighbors are hand-configured over TCP/179; routes carry path attributes, and one deterministic list picks the winner. Memorize the order — it is asked in nearly every senior interview.

Fig 9. The decision funnel — each tier eliminates candidates until one route survives. Ties rarely fall past step ⑧ in real networks.
Peering states: Idle → Connect → Active → OpenSent → OpenConfirm → Established. "Stuck in Active" = TCP/179 can't complete: wrong remote-as, ACL/firewall, or unreachable peer address. iBGP won't re-advertise iBGP-learned routes (split-horizon) — that's why full mesh or route reflectors exist.

5.1 Three-tier campus PACKET TRACER

Fig 16. Hierarchical campus. Each layer has one job; policy lives at distribution, never in the core. Modern shift: push L3 to access (routed access) or replace with a fabric.

5.2 Spine-leaf + VXLAN-EVPN overlay/underlay CML / Nexus 9000v

Fig 17. The underlay (grey, routed links) only knows how to reach loopbacks. The overlay (teal, VXLAN) makes VM-A and VM-B think they share a wire. One-liner: "underlay moves VTEP-to-VTEP packets; EVPN tells VTEPs where every MAC lives."

5.3 Purdue model / IEC 62443 zones & conduits OT CORE

Fig 18. Purdue levels grouped into IEC 62443 zones; every red crossing is a conduit secured to the level of the most critical zone it touches. Modbus TCP/502 and DNP3 TCP/20000 have no auth or crypto — the conduit is the security control. Make outbound rules as strict as inbound.
